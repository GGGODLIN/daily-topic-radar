🆕 CC CLI release

官方發行說明 v2.1.326：發布時間 2026-11-16T22:11:05Z。以 Last seen v2.1.325（2026-11-13T20:40:01Z）為基準，本輪官方清單中發布時間較晚的 release 僅有 v2.1.326；以下依 ProbeReview 更正後核准內容整理。

  • Hooks 的改寫與阻擋：官方記載，多個 PreToolUse hook 回覆同一工具呼叫時，改善 updatedInput 保留，使改寫在更多情況下生效；decision:block 也在更多情況下生效，始終輸出 block 的 hook 因此可能開始阻擋呼叫。這不是每種 hook 組合都已實測通過的保證。
  • 批准改寫後的 sandbox：如果權限 hook 或 SDK host 在批准時改寫指令，且原指令已按 sandboxed 檢查，改寫後指令會留在 sandbox；批准端可在改寫時加入 dangerouslyDisableSandbox:true。HTTP hooks 忽略設定中的 Content-Length、Transfer-Encoding，長度由 body 決定；另調整 allowedHttpHookUrls 與 httpHookAllowedEnvVars 套用至 managed settings hooks 的方式。
  • 權限收斂：Code Mode 中更多 sandboxed 指令會詢問或拒絕；macOS 部分先前能執行的 Bash 指令改為詢問或拒絕。部分 bypass permissions mode 呼叫仍需批准，無人可詢問時拒絕。macOS／Linux／WSL 的 sandboxed 指令預設不能寫入部分敏感家目錄，可用 user 或 managed settings 的 sandbox.filesystem.allowWrite 放行相應位置。
  • 資料夾與 worktree：本機終端的 --add-dir／/add-dir 對尚未受信任的資料夾顯示信任提示，claude --bg 則拒絕它們。以 worktree 隔離的 subagent 會在任何 repository 拒絕部分可改寫共用分支的 Bash git 指令，該條不影響 sessions。若背景 subagent 或 shell 可能仍在 worktree 內執行，ExitWorktree 拒絕移除，除非傳入 discard_changes。
  • MCP 結果與 schema：修復兩個並行長結果在同一毫秒抵達時讀到另一呼叫儲存結果的問題；修復以工具完整名稱搜尋卻載入另一 server 工具，以及根層 anyOf／oneOf 只呈現第一分支參數的問題。如果雲端 session 經 proxy 送出 MCP 呼叫後中斷，會告知結果未知，不能視為沒有執行。
  • Workflow／背景執行：resume 在呼叫失敗後改回報已重用結果數量與停止位置，不再聲稱每個已完成 agent 都會重用。如果背景 session 在崩潰、從另一資料夾重開或背景服務缺設定時遺失 shell 匯出的 LLM gateway，會在模型請求前停止。另修復 process number 被其他使用者程序重用時錯殺程序，以及 Stop hooks 與背景工作同時進行時 /goal clear／新 /goal 未保存。
  • Agents／Code Mode：新增 agent teams 啟用時開啟 Code Mode 的支援；修復 Code Mode 背景 subagent 預載含 inline ! 指令的 skill 時失敗、回合結束後 agent 列仍顯示忙碌，以及單則回覆啟動至少三個 agent 時計數停在二。
  • 搜尋／恢復／TUI：修復 Bash grep 靜默略過部分文字檔、空白回覆後崩潰導致恢復時遺失近期回合、記憶體不足後恢復時遺失早期歷史；改善長 session 打字、串流、縮放反應與 git repository 中 /compact 後第一則訊息的回應時間。這些是發行說明，不是本機延遲量測。
