v2.1.308 官方發行說明（2026-10-22 04:34:55 UTC）僅寫「Bug fixes and reliability improvements」；v2.1.309 官方發行說明 發布於 2026-10-22 22:18:57 UTC。以下按工作鏈分類整理 v2.1.309 記載的變更：

  • Sandbox／檔案邊界：官方記載修復 macOS／Linux 的 sandboxed Bash 在每次執行前於 sandbox 外跑 shell startup files；修復 macOS denyWrite glob 經 symlink 未套至真實位置、profile store 經 symlink 的寫入保護，以及 sandboxed commands／自動接受編輯可改動 --mcp-config 檔案。
  • Bash 權限：修復信任由重導向可能失敗的指令設定的變數；部分帶包裝或前綴的 cd 後接 git 指令未提示權限；同時含 subshell 的重導向寫入漏過 Edit(path) deny rule。worktree guard 亦修補 locale 前綴與 zsh 算術指令的放行問題。
  • MCP／agents：修復 print／SDK session 後續權限提示重新連接已停用的 MCP server；split-pane teammates 現在正確繼承 leader 命令列的 tool deny 與 --tools 規則。ctrl+o 會在 transcript 下方完整顯示其他 agent／session 尚待交付的訊息並標 waiting。
  • Hooks／skills：修復 shell 修改巢狀 package 後，/verify／/code-review 未找到 package 專用 skill；修復 PowerShell hook 的 exit 2 未阻擋，以及 Windows 未裝 Git for Windows 時特定 PowerShell hooks fail-open；mod 的 turn.step 現在解析 haiku 等 model alias。
  • Compaction／紀錄：修復大型巢狀 CLAUDE.md 造成反覆壓縮；超過大小限制的檔案現在只載入開頭。長工具輸出預覽切在 emoji 中間、導致 jq 不能解析 transcript 的問題亦列為修復。
  • 操作契約：sed -i 改走標準 Bash 提示並按原指令執行，不再提供模擬編輯預覽，且不由 /rewind 還原。claude ultrareview 要求 workspace trust；腳本可用不帶值的 --trust-workspace，PR 編號／base branch 要放在該旗標之前。worktree 建立與重用時，一般 clone 不再按需抓 objects；有 Bash sandbox 的 partial clone 則改為先抓取。

★★★ 我會把這批列為日常 CLI 的邊界修復資訊，尤其是 symlink、MCP 設定與 teammate 權限繼承；它們直接對上工具派工與多 worktree 使用情境。發行說明不等於已證明本機所有入口與權限組合都受保護。
