  • hydro-project/infinity 定位為「有原則的 agent 併發 runtime 與工具協定」；jdbrewer/ccfleet 是 HN 上的「安靜、tmux 原生 Claude Code 儀表板」；MiniMax-AI/mcode-stack 放出 MiniMax Code 團隊自己用的 workflows 與 skills。
